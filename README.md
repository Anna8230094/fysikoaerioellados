# 📊 Campaign Management Platform – Φυσικό Αέριο Ελλάδος

This project is a web-based platform designed for managing marketing and customer campaigns at **Φυσικό Αέριο Ελλάδος**. It enables users to insert and update campaign data, check campaign reports, and manage customer call schedules.

> 🔗 [GitHub Repository](https://github.com/Anna8230094/fysikoaerioellados)

---

## 🌐 Technologies Used

- HTML
- CSS
- JavaScript
- Figma (for UI design)

## 📚 Use Cases

### 1. Insert & Upgrade Campaign Requirements
Employees from Marketing, Finance, and Billing departments can insert or edit campaign criteria and customer filters.

### 2. Check Campaign Reports
All departments can access campaign outcomes, feedback, and performance metrics.

### 3. Scheduled Calls
Customer Service Agents can review and manage scheduled calls via an integrated calendar.
